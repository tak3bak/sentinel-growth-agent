# Security Policy for Sentinel Growth Agent
## Supported Versions
The following versions of the Sentinel Growth Agent are currently being supported with security updates.

| Version | Supported |
| :--- | :--- |
| v1.x | :white_check_mark: |
| < v1.0 | :x: |

## Reporting a Vulnerability
Please do not report security vulnerabilities through public GitHub issues. 
Instead, please report them privately to the Nomadik Security Operations team by emailing kalen.vandenbos@gmail.com. We take all security vulnerabilities in our automated infrastructure seriously. We will acknowledge receipt of your report within 48 hours and keep you updated on our progress as we investigate and deploy a fix.
